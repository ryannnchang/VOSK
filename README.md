# VOSK

Script used to run open source VOSK model
Currently uses most lightweight model (40mb)
All models are here: https://alphacephei.com/vosk/models

#Setting up

1. Use python 3.5-3.9
2. Make a virtual-env (Ex: python3.7 -m venv env)
3. Run python source/bin/activate
4. Run pip install -r requirements.txt
5. Run python main.py'
